One glyph that stands for Jablud, the agent that takes a one-line brief
and conjures a finished build out of it before morning: **🧙 the mage**.

No robot, no smiley — the obvious picks say nothing about how this agent
works. The mage is picked by scoring in `portrait.ts` (glance, instant
read, specificity, distinctiveness, tone) and written to
`/output/entry.txt` by `main.ts`.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
